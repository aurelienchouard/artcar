# Artcar

A standalone project for the art car, kept separate from `aurora-dashboard`.

## Layout

```
artcar/
├── docs/       # design notes, build plans, specs
├── src/        # code (lighting, sound, control, etc.)
└── assets/     # images, sketches, media
```

## Getting started

```bash
git clone https://github.com/aurelienchouard/artcar.git
cd artcar
```
